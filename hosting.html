Web Hosting y Dominios

Conceptos fundamentales para publicar un sitio web y hacerlo accesible desde Internet.

¿Qué es Web Hosting?

El Web Hosting o alojamiento web es un servicio que permite guardar los archivos de un sitio web en servidores conectados a Internet.

Cuando una persona entra a una página web, el navegador solicita sus archivos al servidor y posteriormente muestra el contenido. 

Usuario
   ↓
Navegador
   ↓
Internet
   ↓
Servidor
   ↓
Archivos del sitio web
   ↓
Página mostrada

¿Qué se puede guardar en un hosting?

Un servicio de hosting puede almacenar diferentes elementos necesarios para que una página funcione.

HTML

Estructura y contenido de las páginas.

CSS

Diseño, colores, tamaños y estilos.

JavaScript

Interactividad y comportamiento.

Imágenes

Fotografías, logos e ilustraciones.

Tipos de Hosting

Tipo Características Uso común
Compartido Varios sitios utilizan recursos del mismo servidor. Sitios pequeños y proyectos básicos.
VPS Un servidor físico se divide en servidores virtuales. Proyectos que necesitan más control.
Cloud Utiliza recursos distribuidos en infraestructura de nube. Aplicaciones y proyectos que pueden crecer rápidamente.

¿Qué es un dominio?

Un dominio es el nombre que una persona escribe en el navegador para acceder a un sitio web.

Por ejemplo: 

nicolefashion.com

Los dominios hacen que sea más sencillo recordar y visitar un sitio en lugar de utilizar una dirección numérica.

Partes de un dominio 

www.nicolefashion.com
│       │             │
│       │             └── Extensión
│       │
│       └──────────────── Nombre del dominio
│
└──────────────────────── Subdominio
Parte Ejemplo Descripción
Subdominio www Identifica una sección o variante del dominio.
Nombre nicolefashion Nombre elegido para el sitio.
Extensión .com Parte final del dominio.

¿Qué es un TLD?

TLD significa Top-Level Domain. Es la parte final de un dominio.

.com

Muy utilizado para sitios comerciales y proyectos generales.

.org

Frecuente en organizaciones y proyectos comunitarios.

.edu

Asociado principalmente con instituciones educativas.

.sv

Extensión territorial correspondiente a El Salvador.

¿Qué es un subdominio?

Un subdominio es una parte adicional que se coloca antes del dominio principal para identificar una sección específica. 

blog.nicolefashion.com

blog
  ↓
Subdominio

nicolefashion
  ↓
Dominio

.com
  ↓
TLD

Por ejemplo, una tienda podría utilizar un subdominio para separar un blog o una sección de ayuda.

¿Qué es DNS?

DNS significa Domain Name System. Su función principal es ayudar a relacionar nombres de dominio con la información necesaria para encontrar los servidores correspondientes.

Gracias al DNS, podemos utilizar nombres fáciles de recordar en lugar de depender directamente de direcciones IP.

Conclusión

El Web Hosting permite almacenar y publicar los archivos de un sitio web para que puedan ser consultados desde Internet.

Por otra parte, el dominio proporciona una dirección fácil de recordar para acceder al sitio. El DNS ayuda a relacionar ese nombre con la infraestructura donde está publicado.

En el caso de NICOLE FASHION, GitHub puede utilizarse para guardar el código y Vercel para realizar el despliegue del proyecto.
