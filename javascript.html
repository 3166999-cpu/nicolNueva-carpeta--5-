INVESTIGACIÓN 01

JavaScript

El lenguaje que permite agregar comportamiento, interacción y dinamismo a las páginas web.

¿Qué es JavaScript?

JavaScript es un lenguaje de programación utilizado principalmente para crear páginas web interactivas. A diferencia de HTML y CSS, JavaScript permite que una página pueda responder a las acciones que realiza el usuario.

Por ejemplo, JavaScript puede utilizarse para mostrar mensajes, validar formularios, cambiar contenido, realizar cálculos, crear animaciones y responder a eventos como un clic.

En este proyecto, JavaScript permite agregar interactividad al sitio NICOLE FASHION y también controlar funciones como el modo oscuro y el cuestionario.

HTML, CSS y JavaScript

Las tres tecnologías cumplen funciones diferentes dentro de una página web.

Tecnología Función Ejemplo
HTML Define la estructura y el contenido. Títulos, imágenes, botones y secciones.
CSS Define la apariencia visual. Colores, tamaños, espacios y diseños.
JavaScript Agrega comportamiento e interacción. Clics, cálculos, animaciones y validaciones.

Variables

Una variable sirve para almacenar información que puede utilizar un programa.

En JavaScript se pueden utilizar principalmente las palabras reservadas let y const. 

let nombre = "Nicole";

const precio = 45;

let cantidad = 2;

En el ejemplo, la variable nombre guarda un texto, mientras que precio y cantidad guardan números.

Funciones

Una función es un bloque de código que permite realizar una tarea determinada. 

function calcularTotal(precio, cantidad) {

    return precio * cantidad;

}

let total = calcularTotal(45, 2);

console.log(total);

En este ejemplo la función recibe el precio y la cantidad, realiza una multiplicación y devuelve el resultado.

Eventos

Los eventos permiten que JavaScript reaccione a acciones realizadas por el usuario.

Algunos eventos comunes son:

  • click
  • mouseover
  • keydown
  • submit
  • change

Ejemplo práctico

En el siguiente ejemplo utilizaremos JavaScript para cambiar el contenido de una página cuando el usuario presione un botón. 

function saludarNicole() {

    const mensaje =
        document.getElementById("mensajeJS");

    mensaje.innerHTML =
        "¡Hola! JavaScript está funcionando correctamente.";

}
Presiona el botón para ejecutar JavaScript.

¿Para qué se utiliza JavaScript?

Interactividad

Permite responder a las acciones realizadas por los usuarios.

Formularios

Puede validar los datos ingresados antes de enviarlos.

Animaciones

Permite crear efectos visuales y modificar elementos de la página.

Aplicaciones web

Puede utilizarse para construir aplicaciones completas que funcionan desde el navegador.

Conclusión

JavaScript es una tecnología importante para el desarrollo web porque permite transformar una página estática en una experiencia interactiva. Trabajando junto con HTML y CSS, permite crear sitios más dinámicos y funcionales.
