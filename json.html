JSON

Formato utilizado para organizar, guardar y transmitir información entre diferentes sistemas.

¿Qué es JSON?

JSON significa JavaScript Object Notation. Es un formato de texto utilizado para representar y transportar información de una manera organizada.

Aunque su nombre está relacionado con JavaScript, JSON puede utilizarse con diferentes lenguajes de programación.

En las páginas web es muy utilizado para enviar y recibir información entre el navegador, los servidores y las APIs.

¿Para qué sirve JSON?

JSON permite representar datos de una manera sencilla para que diferentes programas puedan intercambiarlos.

Guardar datos

Puede utilizarse para organizar información de productos, usuarios, configuraciones y otros datos.

Intercambiar datos

Facilita el intercambio de información entre aplicaciones y servidores.

Trabajar con APIs

Muchas APIs utilizan JSON para enviar información al navegador.

Clave y valor

Una característica importante de JSON es que la información normalmente se organiza utilizando pares de clave y valor. 

{
    "nombre": "Nicole",
    "edad": 16,
    "ciudad": "Santa Tecla"
}

En este ejemplo:

  • nombre es la clave.
  • "Nicole" es el valor.
  • edad es la clave.
  • 16 es el valor.

Objetos y arrays en JSON

JSON puede utilizar objetos y arrays para organizar diferentes tipos de información.

Objeto 

{
    "producto": "Vestido Elegance",
    "precio": 45,
    "categoria": "Vestidos"
}

Array 

[
    "Vestidos",
    "Pantalones",
    "Blusas",
    "Accesorios"
]

Los objetos utilizan llaves { }, mientras que los arrays utilizan corchetes [ ].

JavaScript vs JSON

Aunque pueden parecer iguales, un objeto de JavaScript y una cadena JSON no son exactamente lo mismo.

Objeto JavaScript 

const producto = {
    nombre: "Vestido Elegance",
    precio: 45
};

Es un objeto que puede utilizarse directamente dentro de JavaScript.

Texto JSON 

{
    "nombre": "Vestido Elegance",
    "precio": 45
}

Es texto con una estructura específica para representar información.

JSON.stringify()

El método JSON.stringify() convierte un valor u objeto de JavaScript en una cadena de texto JSON. :contentReference[oaicite:1]{index=1} 

const producto = {
    nombre: "Vestido",
    precio: 45
};

const datosJSON = JSON.stringify(producto);

console.log(datosJSON);

Esto resulta útil cuando necesitamos preparar datos para enviarlos a otro sistema.

JSON.parse()

JSON.parse() realiza el proceso contrario: toma una cadena JSON válida y la convierte en un valor u objeto que JavaScript puede utilizar. :contentReference[oaicite:2]{index=2} 

const datosJSON = '{"nombre":"Vestido","precio":45}';

const producto = JSON.parse(datosJSON);

console.log(producto.nombre);

JSON y las APIs

JSON es muy común cuando una página web necesita comunicarse con un servidor o con una API.

Por ejemplo, una tienda en línea podría solicitar información de sus productos a un servidor.

Página web Solicita información
→
Servidor Procesa la solicitud
→
JSON Transporta los datos
→
Resultado Se muestra al usuario

Ejemplo aplicado a NICOLE FASHION

En una tienda como NICOLE FASHION, JSON podría utilizarse para organizar los productos disponibles. 

{
    "id": 1,
    "nombre": "Vestido Elegance",
    "categoria": "Vestidos",
    "precio": 45,
    "disponible": true,
    "imagen": "vestido1.jpg"
}

De esta forma, una aplicación podría recibir los datos del producto y utilizarlos para mostrarlo dentro de una página web.

Ventajas de utilizar JSON

  • Es fácil de leer.
  • Tiene una estructura sencilla.
  • Es compatible con JavaScript.
  • Puede utilizarse con diferentes lenguajes.
  • Es utilizado por muchas APIs.
  • Permite organizar datos.
  • Facilita el intercambio de información.
  • Funciona muy bien en aplicaciones web.

Conclusión

JSON es una herramienta importante en el desarrollo web porque permite organizar y transportar información de una manera sencilla.

Su utilización junto con JavaScript facilita la comunicación entre páginas web, servidores y APIs. Los métodos JSON.stringify() y JSON.parse() permiten convertir datos entre objetos de JavaScript y texto JSON.
